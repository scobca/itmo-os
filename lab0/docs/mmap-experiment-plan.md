# План эксперимента `graph_traverse_mmap`

Цель — проверить [гипотезу](mmap-hypothesis.md), сравнив последовательный и случайный mmap-обход.

## Конфигурация

| Параметр | Значение |
|---|---|
| Графы | 1 MiB, seed `427`, `sequential` и `chain` |
| Команда | `./out/graph_traverse_mmap --write --no-cache 100 <graph>` |
| CPU | логический CPU 2 (`taskset -c 2`) |
| Метрика | `real`; дополнительно `user`, `sys`, context switches и page faults |
| Повторы | по 10 на конфигурацию |

Перед основной серией выполняется по одному прогревочному запуску; они заранее исключены из выборки. Затем запуски интерливируются: в нечётных блоках `seq → rand`, в чётных — `rand → seq`, между ними пауза 2 секунды. `strace`, `perf` и фоновая нагрузка в финальной серии не используются.

До и после серии сохраняется состояние системы. Успешные результаты не удаляются как выбросы. Для каждой выборки считаются среднее, стандартное отклонение, медиана, IQR и 95%-й t-интервал; дополнительно анализируется парная разность `rand - seq`.

Сбор воспроизводится [скриптом](../scripts/run_mmap.sh), сырые результаты находятся в [CSV](../logs/mmap/final/graph-traverse-mmap-write-nocache.csv).
