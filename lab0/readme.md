# Лабораторная работа 0

Исследуется влияние физического порядка данных на время обхода файлового графа через `read`/`lseek`. Сравниваются последовательный (`seq`) и случайный (`rand`) графы в режиме `--write --no-cache`.

## Стенд и методика

- Linux 6.11, Intel Core i7-4770, 16 GiB RAM, HDD 1 TB 5400 об/мин.
- Графы: 1 MiB, seed `427`, одинаковое число вершин.
- По 10 запусков на конфигурацию, CPU 2, интерливинг `seq → rand` / `rand → seq`.
- Метрика: полное время `real`; 95%-й доверительный интервал по t-распределению.

## Результат

| Режим | Среднее, с | Медиана, с | CI95, с |
|---|---:|---:|---|
| `seq` | 7,802 | 7,785 | [7,742; 7,862] |
| `rand` | 9,484 | 8,745 | [7,742; 11,226] |

`rand` медленнее в каждом из 10 блоков; разница средних составляет 21,56%. Направление эффекта согласуется с гипотезой, но из-за редкой задержки 15,98 с интервалы пересекаются, поэтому строгого подтверждения на уровне 95% пока нет.
